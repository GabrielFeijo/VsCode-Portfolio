🥇 Certificados

Diploma em Análise e Desenvolvimento de Sistemas

  • A graduação em Análise e Desenvolvimento de Sistemas, forma profissionais qualificados para projetar, implementar e gerenciar sistemas de software. Com uma grade curricular abrangente e atualizada, a graduação combina teoria e prática, permitindo que os alunos desenvolvam habilidades essenciais em desenvolvimento de software, arquitetura de sistemas e gestão de projetos.

Aperfeiçoamento em Desenvolvimento Back-end

  • O curso de Aperfeiçoamento em Desenvolvimento Back-end é voltado para estudantes e profissionais da área de TI, que desejam aprimorar suas habilidades no desenvolvimento da parte server-side de aplicativos web. O foco principal do curso é a implantação de processos de codificação eficientes, visando o funcionamento robusto e escalável de aplicações.

Fundamentos de Lógica de Programação

  • O curso Fundamentos de Lógica de Programação da Fundação Bradesco é indicado para quem quer começar a aprender sobre programação e para quem deseja ter uma base sólida em lógica de programação antes de partir para outras linguagens de programação mais avançadas.

HTML e CSS

  • O curso de HTML e CSS da Fundação Bradesco é um curso online gratuito que tem como objetivo ensinar os conceitos básicos de desenvolvimento web utilizando as linguagens HTML e CSS.

Introdução ao JavaScript

  • O curso Introdução ao JavaScript da Fundação Bradesco é indicado para quem deseja se iniciar na linguagem de programação JavaScript e para quem deseja desenvolver habilidades para criar soluções para web mais dinâmicas e interativas.

Linguagem de programação Java

  • O curso de Linguagem de Programação Java da Fundação Bradesco é indicado para quem deseja se aprofundar na linguagem de programação Java e ter uma base sólida para desenvolver aplicativos, sistemas e outras soluções usando essa linguagem.

Iniciante em programação

  • A formação em programação Oracle+Alura é uma iniciativa da Alura, uma plataforma de ensino online, em parceria com a Oracle, uma empresa de tecnologia conhecida por seus bancos de dados.

Decola Tech 2ª Edição

  • O bootcamp da Avanade + DIO (Digital Innovation One) é uma iniciativa de treinamento intensivo em tecnologia, desenvolvimento de software e inovação. A Avanade é uma empresa global de soluções de tecnologia, enquanto a DIO é uma plataforma de ensino online que oferece cursos gratuitos e de alta qualidade para desenvolvedores de software.
